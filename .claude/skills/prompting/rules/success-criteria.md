# Start with Success Criteria

Define the desired outcome before polishing prompt wording.

Capture the details that change behavior:

- The result to produce.
- The intended audience or consumer.
- Important constraints and non-goals.
- The condition that means the task is done.
- The evidence or fixture used to judge quality.

For production prompts, create representative eval cases before optimizing prose when practical.

If the real bottleneck is missing retrieval, an unsuitable model, latency, cost, tool design, or product design, identify that directly. More prompt text will not reliably solve a non-prompt problem.

For a selected-line edit, infer success from the surrounding prompt unless the line's purpose is unclear. Ask only when different interpretations would materially change the rewrite.
